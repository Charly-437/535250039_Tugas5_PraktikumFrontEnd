# Tugas Praktikum Front-End

Repositori ini dibuat untuk memenuhi Tugas mata kuliah Front-End Programming sesi Praktikum. Fokus utama dari tugas ini adalah membuat halaman Landing Page menggunakan framework Next.js dan React-Bootstrap, yang mencakup komponen Navbar responsif dan Hero Section (Slider Carousel).

## Teknologi yang Digunakan
- Next.js (App Router)
- React-Bootstrap & Bootstrap 5 (untuk komponen UI & styling)
- Material UI / MUI (untuk icon)
- TypeScript

## Cara Menjalankan Proyek
1. Clone repositori ini atau ekstrak foldernya
2. Buka terminal di dalam folder proyek, lalu jalankan:
   ```bash
   npm install
3. Setelah semua dependensi terinstal, jalankan server pengembangan:
   ```bash
   npm run dev
4. Buka http://localhost:3000 di browser untuk melihat hasilnya.
